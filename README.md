# React Portfolio Starter

A beginner-friendly portfolio starter built with React, Vite, CSS, and Lucide icons.

## Run locally
1. Install Node.js (LTS) if it is not already installed.
2. Extract this folder.
3. Open the folder in VS Code.
4. Open Terminal in VS Code and run:
   ```bash
   npm install
   npm run dev
   ```
5. Open the local URL shown in the terminal.

## Personalize before publishing
Search `src/main.jsx` for and replace:
- `Your Name`
- `YOUR-GITHUB-USERNAME`
- `YOUR-LINKEDIN-USERNAME`
- `YOUR-EMAIL@example.com`
- `Your college or university name`
- Project placeholders and descriptions

Only list skills and projects that accurately represent your work. Add your real profile URLs after creating those accounts.

## Build for deployment
```bash
npm run build
```
The production website is created in the `dist` folder.

## Deploy
Push the project to a GitHub repository, then import that repository into Vercel and deploy it using the Vite defaults. After deployment, open the live URL and test all links.
